## 📋 **ESTRUCTURA DE WIDGETS EN JSON:**

Cada tema incluye configuración JSON con:

```json
{
  "widgets": {
    "calendario_audiencias": true,
    "documentos_pendientes": true,
    "estadisticas_dashboard": true
  },
  "layout": {
    "sidebar_position": "left",
    "widget_columns": 3,
    "dashboard_style": "cards"
  },
  "calendario": {
    "mostrar_en_home": true,
    "eventos_por_pagina": 15,
    "color_eventos": "#1e3a8a",
    "vista_predeterminada": "mes"
  }
}
```
