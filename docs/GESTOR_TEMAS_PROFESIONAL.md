## 🚀 Cómo Usar

### Acceder al Gestor
```
http://127.0.0.1:9000/admin/temas/1/edit
```

### Configurar Altura y Ancho de Banners

1. **Scroll** hasta la sección **"🎬 Banners Hero"**

2. **Altura Desktop**:
   - Mínimo: 400px (banner bajo)
   - Recomendado: 700-900px (impacto visual)
   - Máximo: 1200px (muy imponente)
   - **Actual**: 800px

3. **Altura Móvil**:
   - Mínimo: 300px (compacto)
   - Recomendado: 500-650px (balance)
   - Máximo: 800px (muy grande)
   - **Actual**: 600px

4. **Tipo de Ancho**:
   - **Container**: Limitado a 1140px (márgenes grandes)
   - **Ancho Completo**: ~95% de pantalla (se aprecia toda la foto) ✅

5. **Padding Lateral**:
   - 0%: Sin márgenes (100% ancho)
   - 3%: Márgenes pequeños
   - 5%: Márgenes medianos ✅ (Recomendado)
   - 10%: Márgenes grandes

### Guardar Cambios

1. Scroll hasta abajo
2. Clic en **"Actualizar"**
3. Ver mensaje: "Tema actualizado exitosamente"
4. Ir a: http://127.0.0.1:9000/
5. Presionar: `Ctrl + Shift + R`

## 🐛 Solución de Problemas

### Problema: No veo las nuevas secciones

**Solución**: Limpiar caché
```bash
php artisan cache:clear
php artisan view:clear
```

### Problema: Los cambios no se reflejan en el sitio

**Solución 1**: Verificar que es el tema predeterminado
- En el listado de temas debe tener badge "Predeterminado"

**Solución 2**: Limpiar caché
```bash
php artisan cache:clear
```

**Solución 3**: Limpiar caché del navegador
```
Ctrl + Shift + R
```

### Problema: Error al guardar

**Verificar** valores en rangos permitidos:
- Altura Desktop: 400-1200px
- Altura Móvil: 300-800px
- Altura Navbar: 50-120px

## 💡 Mejores Prácticas

### Para Banners
- **Desktop**: 700-900px (sweet spot)
- **Móvil**: Proporcional, ~75% del desktop
- **Ancho**: Container-fluid para fotos panorámicas
- **Padding**: 5% para margen respirable

### Para Navbar
- **Altura**: 60-80px (ni muy grande ni muy pequeño)
- **Color**: Contraste con el banner, armonía con marca
- **Transparente**: Solo si el banner es oscuro

### Para Espaciado
- **Secciones**: 80px da buen ritmo visual
- **Border Radius**: 8px es moderno sin ser excesivo
- **Sombras**: Normal es suficiente, pronunciada solo para destacar

### Para Botones
- **Border Radius**: 4-8px para profesional, 50px para moderno
- **Padding**: Normal (10px 20px) es versátil

### Para Animaciones
- **Activar**: Sí, mejora experiencia de usuario
- **Velocidad**: 0.3s es el estándar web
