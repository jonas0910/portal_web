### 🚀 **Instalación y Despliegue:**

#### **Instalación Rápida**
```bash
# Opción 1: Script automático
install.bat  # Windows
./install.sh # Linux/Mac

# Opción 2: Manual
composer install
npm install
cp env.example .env
php artisan key:generate
# Configurar DB en .env
php artisan migrate --seed
npm run build
php artisan storage:link
php artisan serve
```
