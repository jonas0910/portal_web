## 🚀 GUÍA RÁPIDA DE USO

### Para Subir Logos
1. Admin → Contenido → Configuración del Sitio
2. Sección "General"
3. Subir `logo_header` (200x80px) y `logo_navbar` (50x50px)
4. Guardar

### Para Configurar Banners
1. Admin → Contenido → Banners
2. Crear/Editar banner
3. Seleccionar imagen o video (hasta 20MB/100MB)
4. Configurar título, subtítulo, botón
5. Guardar
6. Ver en http://127.0.0.1:9000/

### Para Ajustar Diseño del Banner
1. Admin → Temas → Editar
2. Sección "🎬 Banners Hero"
3. Ajustar altura, ancho, padding, ajuste de imagen
4. Guardar
5. Recargar portal (Ctrl + Shift + R)

### Para Gestionar Menús
1. Admin → Menús
2. Crear menú principal (sin parent_id)
3. Crear submenús (con parent_id del menú principal)
4. Configurar orden y URLs
5. Ver en navbar del portal
