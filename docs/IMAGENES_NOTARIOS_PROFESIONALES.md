## 🔧 **CÓMO USAR IMÁGENES EN EL SISTEMA**

### **1. URLs Externas (Unsplash, Pixabay, etc.):**
- Al crear/editar banners o páginas
- Simplemente pega la URL completa de la imagen
- El sistema detectará automáticamente que es externa
- No se almacena localmente (ahorra espacio)

### **2. Archivos Locales:**
- Sube archivos desde tu computadora
- Se almacenan en `storage/app/public/`
- El sistema genera las URLs automáticamente

### **3. Parámetros de URL de Unsplash:**
```
?w=1920         - Ancho en píxeles
&h=600          - Alto en píxeles
&fit=crop       - Recortar para ajustar
&q=80           - Calidad (1-100)
&auto=format    - Formato automático (webp si es soportado)
```
