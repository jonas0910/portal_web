## 📱 CÓMO USAR LA NUEVA INTERFAZ

### Paso 1: Acceder
```
http://127.0.0.1:9000/admin/plantillas/19/edit
```

### Paso 2: Navegar por Categorías
1. Click en la pestaña de la categoría deseada:
   - 🖼️ **Hero & Presentación** - Para elementos principales
   - 📰 **Contenido Dinámico** - Para noticias, proyectos
   - ℹ️ **Información & Datos** - Para servicios, notarios
   - 🤝 **Interacción** - Para formularios
   - 📸 **Multimedia** - Para galerías

### Paso 3: Activar Componentes
Dentro de cada categoría:
1. **Activar** el switch del componente deseado
2. Se abrirá automáticamente el panel de configuración
3. **Configurar** las opciones específicas:
   - Orden de aparición (1 = primero)
   - Color de fondo
   - Cantidad de elementos
   - Columnas
   - Opciones de visualización

### Paso 4: Guardar
Click en **"Guardar Cambios"** al finalizar
